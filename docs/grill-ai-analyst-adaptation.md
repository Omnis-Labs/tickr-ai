# Grill AI Analyst adaptation

Source map: `Fundamental_analysis_agent/docs/AGENTS.md` plus each task folder. Hunch It does not mount the Python app. It ports only agents whose real data path can produce a meaningful Analyst Opinion for one supported Hunch It asset using Hunch-native TypeScript and Pyth bars now.

Default selected team remains Technical Tape, Relative Strength, and Volatility Regime so Grill works immediately without forcing the user to configure Team first.

The null-control analysts are exposed only as controls. They always return a `challenge` verdict, preserve the source caveat that they have no economic mechanism, and cannot by themselves support Proposal creation. T27/T29/T31/T33 use the first visible Hunch/Pyth bar as the explicit Hunch natal anchor because reliable listing-date metadata is not yet part of the Grill input. T33 also uses a deterministic fixed-boundary solar-sign approximation instead of Python `ephem`; that is acceptable only because the analyst is a placebo challenge, not a trading-support signal.
